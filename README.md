# CodeAlpha Task 1 - Web Scraping

## Objective
Collect book information from the public Books to Scrape practice website using Python, Requests and BeautifulSoup.

## Data collected
- Book title
- Price
- Availability
- Rating
- Page number

## How to run
```bash
pip install -r requirements.txt
python scrape_books.py
```

The script creates `books_scraped.csv`.

## Learning outcome
This task demonstrates HTML parsing, extracting structured fields, basic cleaning and exporting a dataset to CSV.
